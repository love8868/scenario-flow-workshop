# 套图工坊美工生图标准样板（独立标准版）

> 定位：独立标准样板，以网页项目“套图工坊”命名，重新完整定义，不依附于任何已有项目，
> 与此前任何实例、旧项目互不引用。任何产品的生图流程都可按此执行。
> 输入：产品基本信息 + 场景需求。最终产出：通过验收的一套图 + 全部提示词 + 分级检查表。
> 模型说明：现阶段不输入外部模型 Key，由执行者自身能力顶上（写提示词、做检查、做纸面推演）；
> 后续补 Key 后，同一流程直接换模型执行，流程本身不变。

## 流程图（文字版）

```
[查产品] ──► [出场景和提示词] ──► ◎ 人工验收（提示词可改）
   ──► [合成生图] ──► [看图员分级检查] ◆
   ├── 通过 ──► ◎ 人工验收（图） ──► [通过]
   ├── PS 可补 ──► [PS 补足] ──► ◎ 人工验收（图） ──► [通过]
   └── 必须返修 ──► ↻ 最多 3 轮，回到 [出场景和提示词]
■ 红线：主图必须实拍直出；主体结构、比例、机位错了必须返修，PS 补不了
```

## 角色卡

- **侦察兵**：goal 查清产品信息和实拍图。输入：产品基本信息。输出：产品名、规格、材质、关键特征、实拍图。终止：信息齐全或已标明缺失项，缺失不猜。
- **美工**：goal 出场景方案和提示词。输入：产品信息 + 场景需求。输出：提示词（固定层 + 变量层）。约束：提示词只描述场景，不碰产品外形描述；机位只在变量层有特殊要求时才写。终止：提示词通过人工验收。
- **码农**：goal 按通过验收的提示词合成生图。输入：提示词。输出：成图。终止：图已生成且可查。
- **看图员**：goal 分级检查成图。输入：成图 + 产品实拍图。输出：分级检查表（通过 / PS 可补 / 必须返修，逐项标明）。终止：检查表完成。
- **PS 修图**：goal 补足 PS 可补的缺陷。输入：成图 + 分级检查表。输出：修后图。约束：只补表面，不改结构。终止：修后图已出。
- **军师**：goal 汇总验收。输入：检查表 + 成图。输出：通过 / 返修（写明原因，对应到返修分类）。终止：已裁决。

| 步骤 | 谁干 | 输入 | 产出 | 下一步交给谁 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 1 | 侦察兵 | 产品基本信息 | 产品信息 + 实拍图 | 美工 | 信息缺失要标明，不猜 |
| 2 | 美工 | 产品信息 + 场景需求 | 场景方案 + 提示词 | 人工验收 | 固定层锁死，变量层写定制 |
| 3 | 人工验收 | 提示词 | 通过 / 修改意见 | 美工（返修）或码农 | 可改，改完再验收 |

| 7 | 美工（返修） | 分级检查表 | 新提示词 | 码农 | 返修必须写明原因，对应到分类 |

## 宽容度分级表（核心）

AI 生图变形、细节漂移是预期内的问题，不追求一次完美。验收分三级：

| 缺陷 | 分级 | 判定标准 | 处理 |
| --- | --- | --- | --- |
| 主体结构变形（轮廓、造型变了） | 必须返修 | 与实拍图对比，主体轮廓明显不符 | 返修重生 |
| 多产品同框比例错 | 必须返修 | 相对大小与实拍不符 | 返修重生 |
| 机位角度错（要 3/4 给了正面等） | 必须返修 | 角度与提示词要求不符 | 返修重生 |
| 产品关键特征缺失或错（端口数、按键、接口） | 必须返修 | 特征数量或位置错 | 返修重生 |
| 文字大面积错乱、影响识别 | 必须返修 | 标签、说明文字大面积无法辨认 | 返修重生 |
| 细节漂移（纹理、花纹、小装饰走样） | PS 可补 | 不影响识别和结构 | PS 仿制、局部重绘 |
| 文字小面积错误（单个字母、Logo 小错） | PS 可补 | 小范围、可贴字改字 | PS 改字、贴真实 Logo |
| 边缘小瑕疵（毛边、轻微穿帮） | PS 可补 | 局部小范围 | PS 修边 |
| 颜色轻微偏差 | PS 可补 | 色差在可调范围 | PS 校色 |
| 背景小杂物、杂点 | PS 可补 | 不影响主体 | PS 去除 |
| 无上述问题或仅轻微 | 通过 | — | 直接验收 |

## PS 补足边界

- PS 能补：细节漂移、文字小错、边缘瑕疵、颜色、背景杂物、光影微调。
- PS 不能补：主体结构、比例、机位、关键特征缺失、大面积重构。拿 PS 硬补结构问题只会越补越假，一律返修重生。

## 看图员检查表（逐项打勾 + 定级）

- [ ] 主体结构：轮廓、造型与实拍图是否一致？（不一致 → 返修）
- [ ] 比例：单产品比例、多产品同框相对大小是否正确？（错 → 返修）
- [ ] 机位：角度是否符合提示词要求？（错 → 返修）
- [ ] 关键特征：端口数、按键、接口数量和位置是否正确？（错 → 返修）
- [ ] 文字：标签、Logo 是否可辨认？小错标 PS 补，大面积错乱标返修。
- [ ] 细节：纹理、花纹、小装饰是否走样？（走样但不影响识别 → PS 补）
- [ ] 颜色：与实拍图色差是否在可调范围？（是 → PS 补）
- [ ] 背景与边缘：杂物、毛边、穿帮是否局部小范围？（是 → PS 补）

## 提示词模板

- 固定层（每次都锁死，不随产品变）：品牌视觉、默认机位（3/4 角度）、光影风格（柔和棚拍光）、画幅。
- 变量层（必填，缺一项不接）：产品名、关键特征（端口数、接口、材质）、场景、卖点、特殊机位要求（有才写）、风格要求。
- 模板句式：固定层 + 变量层拼接；提示词只描述场景，不描述产品外形，不锁角度（除非变量层有特殊要求）。

## 返修原因分类（返修必须对应到类）

- 构图类：机位错、比例错。
- 产品类：结构变形、关键特征缺失或错。
- 文字类：文字大面积错乱。
- 风格类：与品牌视觉不符。

## 常见错误

- 提示词把固定层和变量层混写，导致每次风格漂移。
- 验收只看整体不看细节，关键特征错了才发现。
- 返修不写原因，下一轮重犯同一个错。
- 拿 PS 硬补结构问题，越补越假。
- 小瑕疵也返修重生，浪费轮数（小瑕疵走 PS 补）。

## 验收点和护栏清单

- [ ] 验收点 1：提示词人工验收（可改）后才生图。
- [ ] 验收点 2：成图 / 修后图人工验收（可改）后才算通过。
- [ ] 宽容度：按分级表定级，PS 可补的不返修重生，结构性问题必须返修。
- [ ] 禁区：AI 不做白底主图；不改产品外形；不编造规格（端口数、尺寸、材质以侦察兵查到的为准）。
- [ ] 事实核对点：规格、端口数、材质由侦察兵核对，提示词里不许凭空写。
- [ ] 循环上限：返修最多 3 轮，到上限转人工定夺。
- [ ] 产物落盘：提示词、成图、修后图、分级检查表全部留下来可查。

## 演示示例（纸面推演，通用产品，非真实生图）

以一款通用无线鼠标为例，演示本样板怎么走（产品为示例假设，不对应任何真实在售型号）：

- **侦察兵输出**：产品名：无线鼠标；关键特征：左右键、滚轮、DPI 键、2.4G 接收器；材质：磨砂塑料；场景需求：办公桌面场景。
- **美工提示词成品**：固定层（柔和棚拍光、3/4 角度、标准画幅）+ 变量层（无线鼠标、左右键 + 滚轮 + DPI 键、办公桌面场景、卖点：静音按键）拼接成完整提示词；提示词只描述场景，不描述鼠标外形。
- **人工验收（提示词）**：通过，变量层必填项齐全。
- **看图员分级检查（假设成图情况）**：滚轮纹理轻微漂移 → PS 可补；背景有一处小杂物 → PS 可补；主体结构、比例、机位、按键数量均正确 → 不返修。
- **处理**：走 PS 补足（仿制滚轮纹理、去除背景杂物）→ 人工验收（图）通过 → 交付。
- 本节仅演示流程走法，不是真实生图结果；真实生图时同一流程换模型执行，步骤不变。
