# 场景流程工坊

给任何一个场景生成一整套可执行的流程：流程不是从模型里编出来的，
是从这个行业现成的做法里抄来的，再用 Agent 的方法把它固定下来。

方法来源：主干是 MetaGPT 的 SOP 思想；流程控制借 LangGraph 的图思想；
角色写法借 CrewAI 的三要素；讨论会诊借 AutoGen 的群聊；
护栏借 OpenAI Agents SDK 的 guardrails；固定流程与推理的分工借 Google ADK。

## 通用验收规则

提示词和图这类可改的产物：先过目、可人工修改调整、再往下走；
不可逆的动作必须有人拍板才能执行。
