# 旅行规划流程

> 适用场景：一次旅行从定目的地到花费复盘的全过程。
> 输入：目的地意向 + 预算 + 时间。最终产出：确认的行程单 + 花费复盘。

## 流程图（文字版）

```
[定目的地和预算] ──► [行程] ──► [订票订房] ──► ◎ 确认行程单
   ──► [分级检查] ◆
   ├── 通过 ──► [游玩清单] ──► [出行] ──► [花费复盘]
   ├── 可调整 ──► [调整行程] ──► ◎ 确认行程单
   └── 重订 ──► ↻ 回 [行程] 或 [订票订房]
   预算超支 ◆ 回 [行程] 调整；订票订房失败 ◆ 换方案重订
■ 红线：付款前再确认价格和退改政策；证件有效期必须核对
```

## 角色卡

- **规划员**：goal 定出可行的行程。输入：目的地意向 + 预算 + 时间。输出：行程单（每天去哪、交通、住宿、大致花费）。终止：行程单已确认。
- **预订员**：goal 订好票和房。输入：行程单。输出：订单记录 + 退改政策摘要。终止：订单已确认，政策已标明。
- **领队**：goal 按行程执行。输入：确认的行程单 + 游玩清单。输出：出行记录（实际花销、变动）。终止：行程结束。
- **记账员**：goal 复盘花费。输入：预算 + 实际花销 + 出行记录。输出：花费复盘（超支项、省钱项、下次注意）。终止：复盘已定稿。

## SOP 步骤表

| 步骤 | 谁干 | 输入 | 产出 | 下一步交给谁 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 1 | 规划员 | 目的地意向 + 预算 + 时间 | 行程单 | 预订员 | 每天安排留余量，不排满 |
| 2 | 预订员 | 行程单 | 订单记录 + 退改政策摘要 | 确认人 | 付款前再确认价格和退改政策 |
| 3 | 确认人 | 行程单 + 订单记录 | 确认 / 修改意见 | 规划员（调整）或领队 | 证件有效期这一步核对 |
| 4 | 规划员 | 确认的行程单 | 游玩清单（必去、可选、备选） | 领队 | 备选是为天气和体力准备的 |
| 5 | 领队 | 行程单 + 游玩清单 | 出行记录 | 记账员 | 变动当时就记，不事后补 |
| 6 | 记账员 | 预算 + 实际花销 + 出行记录 | 花费复盘 | 规划员（下一次） | 超支项要对应到具体哪天哪项 |

## 细则层

### 宽容度分级表

| 缺陷 | 分级 | 判定标准 | 处理 |
| --- | --- | --- | --- |
| 证件、签证过期或无效 | 重订 | 有效期核对不通过 | 改期或重订 |
| 订票订房失败 | 重订 | 订单未确认 | 换方案重订 |
| 预算大超 | 重订（回行程调整） | 超出预算口径 | 回行程调整 |
| 行程时间小冲突 | 可调整 | 局部可调 | 调顺序或时长 |
| 住宿、交通偏好微调 | 可调整 | 不影响整体 | 直接改 |
| 游玩清单增减 | 可调整 | 必去项不受影响 | 直接改 |
| 无问题 | 通过 | — | 直接出行 |

### 检查表

- [ ] 目的地和预算：预算口径是否定清？（人均还是总额，见待定项）
- [ ] 行程：每天安排是否留余量？交通、住宿、大致花费是否都写了？
- [ ] 预订：价格、时间、地点付款前是否再确认？退改政策是否标明？
- [ ] 证件：有效期是否在确认行程单时核对？
- [ ] 游玩清单：必去、可选、备选是否分清？
- [ ] 出行记录：变动是否当时就记？
- [ ] 复盘：超支项是否对应到具体哪天哪项？

### 行程单模板（结构）

每天：去哪 → 交通 → 住宿 → 大致花费 → 备选。结构固定，内容按目的地填；每天留余量，不排满。

### 返修原因分类

- 证件类：证件、签证过期或无效。
- 预订类：订票订房失败、价格时间地点错。
- 预算类：预算大超。
- 行程类：时间冲突、安排不合理（小冲突走可调整）。

### 常见错误

- 证件有效期不核对。
- 退改政策不明就付款。
- 行程排满无余量。
- 变动事后补记，复盘对不上。
- 复盘不对应到天和项。

### 演示示例（纸面推演，通用行程，非真实执行）

通用 3 天周边游：定目的地和预算 → 行程单 → 订票订房 → 确认时发现第二天上午下午时间冲突 → 定级可调整 → 调换顺序 → 确认通过 → 游玩清单 → 出行（变动当时记）→ 花费复盘（超支项对应到天和项）。本节仅演示流程走法。

## 验收点和护栏清单

- [ ] 验收点：行程单确认后才出行，确认时证件有效期一并核对。
- [ ] 宽容度：按分级表定级，可调整的直接改，证件、预订失败、预算大超才重订。
- [ ] 禁区：不订退改政策不明的票和房；不超预算硬上。
- [ ] 事实核对点：价格、时间、地点付款前再确认一次。
- [ ] 分支处理：预算超支回行程调整；订票订房失败换方案重订，不将就。
- [ ] 不可逆动作：付款，执行前需拍板。
- [ ] 产物落盘：行程单、订单记录、出行记录、花费复盘全部留档。
- [ ] 待定项：预算口径（人均还是总额）、超支比例红线，需经验补，不预设。
