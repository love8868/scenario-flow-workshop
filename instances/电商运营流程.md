# 电商运营流程

> 适用场景：一个产品从选品到售后复盘的全链路。
> 输入：类目方向 + 预算。最终产出：上架商品 + 详情页 + 推广和售后复盘记录。

## 流程图（文字版）

```
[选品] ──► [上架资料] ──► [详情页（含套图）] ──► ◎ 人工验收（详情页可改）
   ──► [分级检查] ◆
   ├── 通过 ──► [推广] ──► [客服] ──► [售后复盘]
   ├── 可修补 ──► [修补] ──► [推广]
   └── 返修 ──► ↻ 回 [详情页]
   推广数据差 ◆ 回 [选品] 或 [详情页] 优化
■ 红线：价格、库存、规格必须真实；不做虚假宣传
```

## 角色卡

- **选品员**：goal 选出值得做的产品。输入：类目方向 + 预算。输出：候选产品 + 理由（需求、竞争、利润测算）。终止：候选清单已定。
- **运营**：goal 备齐上架资料。输入：候选产品。输出：标题、规格、价格、库存。终止：资料齐全且已核对。
- **美工**：goal 做详情页（含套图）。输入：上架资料 + 实拍图。输出：详情页成稿。终止：详情页通过人工验收。
- **推广员**：goal 做推广并看数据。输入：上架商品。输出：推广方案 + 数据记录。终止：数据已记录，优化建议已给。
- **客服**：goal 处理咨询和售后。输入：客户问题。输出：回复记录 + 待解决问题清单。终止：问题已闭环或已升级。
- **复盘员**：goal 总结一轮得失。输入：推广数据 + 客服记录。输出：复盘结论 + 下一步动作。终止：复盘已定稿。

## SOP 步骤表

| 步骤 | 谁干 | 输入 | 产出 | 下一步交给谁 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 1 | 选品员 | 类目方向 + 预算 | 候选产品 + 理由 | 运营 | 理由要有数据，不凭感觉 |
| 2 | 运营 | 候选产品 | 标题、规格、价格、库存 | 美工 | 价格库存必须核对 |
| 3 | 美工 | 上架资料 + 实拍图 | 详情页成稿 | 人工验收 | 套图走美工生图流程 |
| 4 | 人工验收 | 详情页成稿 | 通过 / 修改意见 | 美工（返修）或推广员 | 可改 |
| 5 | 推广员 | 上架商品 | 推广方案 + 数据记录 | 客服 | 数据按天记 |
| 6 | 客服 | 客户问题 | 回复记录 + 待解决问题 | 复盘员 | 解决不了的升级，不硬答 |
| 7 | 复盘员 | 推广数据 + 客服记录 | 复盘结论 + 下一步动作 | 选品员（下一轮） | 结论要对应到动作 |

## 细则层

### 宽容度分级表

| 缺陷 | 分级 | 判定标准 | 处理 |
| --- | --- | --- | --- |
| 价格、库存、规格与实际不符 | 返修 | 核对不一致 | 返修重改 |
| 标题、文案事实错（功效、参数） | 返修 | 虚假或错误 | 返修重改 |
| 详情页缺必备模块（价格、规格、售后任一缺） | 返修 | 模块缺失 | 返修补齐 |
| 文案小错（错别字、语序） | 可修补 | 不影响事实 | 直接改 |
| 图片小瑕疵（裁切、轻微色差） | 可修补 | 不影响识别 | 修图补 |
| 推广数据差 | 优化（非返修） | 数据低于预期 | 回选品或详情页优化 |
| 无问题 | 通过 | — | 直接推广 |

### 检查表

- [ ] 选品：需求、竞争、利润测算是否都有数据？（利润阈值待定，需经验或行业数据补）
- [ ] 上架：标题、规格、价格、库存是否逐项核对？
- [ ] 详情页：主图、卖点、规格、细节、售后模块是否齐全？事实是否与上架资料一致？
- [ ] 推广：数据是否按天记录？优化建议是否对应到数据？
- [ ] 客服：每个问题是否闭环或已升级？
- [ ] 复盘：结论是否对应到下一步动作？

### 详情页模板（结构）

主图 → 卖点 → 规格 → 细节图 → 售后说明。模块顺序固定，内容按产品填；套图部分走美工生图流程。

### 返修原因分类

- 事实类：价格、库存、规格、功效错。
- 结构类：详情页缺必备模块。
- 文案类：错别字、语序、表述不清。
- 图片类：裁切、色差、瑕疵。
- 数据类：推广数据差（走优化，不走返修）。

### 常见错误

- 价格库存未核对就上架。
- 详情页缺售后模块。
- 推广数据不记，复盘无依据。
- 复盘结论不对应到动作。
- 小错也返修重做，浪费轮数（小错直接改）。

### 演示示例（纸面推演，通用产品，非真实执行）

通用不锈钢水杯：选品（需求、竞争、利润测算有数据）→ 上架（标题、规格、价格、库存核对）→ 详情页成稿 → 人工验收发现两处错别字 → 定级可修补 → 直接改字 → 推广 → 客服无遗留问题 → 复盘（结论对应到下一轮动作）。本节仅演示流程走法。

## 验收点和护栏清单

- [ ] 验收点：详情页人工验收后才推广。
- [ ] 宽容度：按分级表定级，可修补的直接改，事实和结构问题必须返修。
- [ ] 禁区：不做虚假宣传；不写没有的规格和功效。
- [ ] 事实核对点：价格、库存、规格上架前再核对一次。
- [ ] 循环上限：详情页返修最多 3 轮。
- [ ] 不可逆动作：上架、改价、投推广费，执行前需拍板。
- [ ] 产物落盘：选品理由、详情页成稿、推广数据、复盘结论全部留档。
- [ ] 待定项：选品利润阈值、推广数据合格线，需经验或行业数据补，不编造。
