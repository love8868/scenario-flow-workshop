# 摄影修图流程

> 适用场景：一次拍摄从拍到交付的全过程。
> 输入：拍摄需求 + 时间地点。最终产出：交付成片 + 原片备份。

## 流程图（文字版）

```
[拍摄] ──► [选片] ──► [修图] ──► ◎ 客户过目（可改） ──► [分级检查] ◆
   ├── 通过 ──► [交付]
   ├── 可修补 ──► [修图返修] ──► ◎ 客户过目
   └── 返修（重拍）──► ↻ 回 [拍摄]，仅限原片不可用、选片错等结构性问题
■ 红线：修图前先备份原片；修图不改变约定之外的外形
```

## 角色卡

- **摄影师**：goal 按需求拍出可用素材。输入：拍摄需求 + 时间地点。输出：原片 + 拍摄记录。终止：原片已备份。
- **选片师**：goal 选出要修的片子。输入：原片。输出：选片清单 + 入选理由。终止：清单已定（客户参与选片时以客户为准）。
- **修图师**：goal 按约定修出成片。输入：选片清单 + 修图约定（风格、程度、禁区）。输出：成片。终止：成片通过客户过目。
- **客户**：goal 验收成片。输入：成片。输出：通过 / 修改意见。终止：已拍板。

## SOP 步骤表

| 步骤 | 谁干 | 输入 | 产出 | 下一步交给谁 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 1 | 摄影师 | 拍摄需求 + 时间地点 | 原片 + 拍摄记录 | 选片师 | 原片当场备份，不只存一张卡 |
| 2 | 选片师 | 原片 | 选片清单 + 入选理由 | 修图师 | 客户参与选片时以客户为准 |
| 3 | 修图师 | 选片清单 + 修图约定 | 成片 | 客户 | 约定外的外形不改 |
| 4 | 客户 | 成片 | 通过 / 修改意见 | 修图师（返修）或交付 | 可改，返修最多 3 轮 |
| 5 | 交付 | 成片 | 交付包（成片 + 格式清单） | 客户 | 格式按约定（尺寸、格式、数量） |

## 细则层

### 宽容度分级表

| 缺陷 | 分级 | 判定标准 | 处理 |
| --- | --- | --- | --- |
| 原片损坏、缺关键镜头 | 返修（重拍） | 原片不可用 | 回拍摄重拍 |
| 选片错（客户要的没选） | 返修（重选） | 清单与需求不符 | 回选片重选 |
| 修图改了约定之外的外形 | 返修（重修） | 外形改动超约定 | 回修图重修 |
| 色调、曝光偏差在约定范围 | 可修补 | 可调范围内 | 微调重导出 |
| 局部瑕疵（杂物、小瑕疵） | 可修补 | 局部小范围 | 局部修补 |
| 格式、尺寸错 | 可修补 | 与约定不符 | 按约定重导出 |
| 无问题 | 通过 | — | 直接交付 |

### 检查表

- [ ] 拍摄：原片是否当场备份？拍摄记录是否齐全？
- [ ] 选片：清单与需求是否一致？客户参与时是否以客户为准？
- [ ] 修图约定：风格、程度、禁区、轮数、格式是否都写清？（程度标准需客户定，见待定项）
- [ ] 修图：约定之外的外形是否没改？色调、曝光是否在约定范围？
- [ ] 交付：尺寸、格式、数量是否按约定核对？

### 修图约定模板（结构）

风格 → 程度 → 禁区（不改的部分）→ 返修轮数 → 交付格式（尺寸、格式、数量）。结构固定，数值按客户约定填，不预设。

### 返修原因分类

- 拍摄类：原片损坏、缺关键镜头。
- 选片类：清单与需求不符。
- 修图类：外形改动超约定、色调曝光超范围。
- 交付类：格式、尺寸、数量错（走可修补重导出）。

### 常见错误

- 原片不备份就修。
- 修图程度约定不写清，事后扯皮。
- 客户意见不具体到哪张、改哪里。
- 小修补也重拍，浪费成本。
- 交付格式不核对。

### 演示示例（纸面推演，通用拍摄，非真实执行）

通用产品静物一组：拍摄当场备份 → 选片清单定 → 修图 → 客户意见“第 3 张色调偏冷” → 定级可修补 → 调色重导出 → 客户过目通过 → 按约定格式交付。本节仅演示流程走法。

## 验收点和护栏清单

- [ ] 验收点：客户过目后才交付，返修意见要具体到哪张、改哪里。
- [ ] 宽容度：按分级表定级，可修补的直接改，原片不可用、选片错、外形改动超约定才返修或重拍。
- [ ] 禁区：修图前未备份不许动原片；约定之外的外形（体型、产品结构）不改。
- [ ] 事实核对点：交付格式（尺寸、格式、数量）交付前再核对。
- [ ] 循环上限：返修最多 3 轮，超出按约定收费或转人工谈。
- [ ] 不可逆动作：交付、删除原片，执行前需拍板。
- [ ] 产物落盘：原片备份、选片清单、成片、客户意见全部留档。
- [ ] 待定项：修图程度标准、超轮数后的约定，需客户约定补，不预设。
